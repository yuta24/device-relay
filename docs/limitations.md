# 既知の制約

device-relay の症状・制約から、説明と対処のある節を引く索引です。横断的な制約はこの文書の後半にまとめています。
全体の入口は [README](../README.ja.md) です。

## 症状・制約から探す

### 要素とタッチ

| 症状・制約 | どうなるか（1 文） | 読む節 |
| --- | --- | --- |
| 要素セレクタ | 完全一致で要素を選びますが、隠れた要素やスナップショットの待ち時間には制約があります。 | [要素セレクタ](elements.md#要素セレクタ) |
| `/type`・`/key` | 文字入力と特殊キーにはキーボードのフォーカスがある要素が必要です。 | [文字入力と特殊キー](http-api.md#文字入力と特殊キー) |
| システムの許可ダイアログと対象アプリ | 許可ダイアログの表示中に後ろのアプリの要素を指定してタッチすると、何も送らずに止まります。 | [システムの許可ダイアログ](elements.md#システムの許可ダイアログ) |
| 覆われていても止まらないタッチ | 前面アプリの一覧が変わらない重なりや、出た直後のダイアログ・シートへのタッチは、成功を返しても届かないことがあります。 | [別のアプリに覆われているとき](elements.md#別のアプリに覆われているとき) |
| 共有シートの中の要素 | 中身の形によっては画面上の位置が決まらず、要素指定のタッチを止めます。 | [共有シートの中の要素](elements.md#共有シートの中の要素) |
| 待機中の前面アプリの切り替え | 要素を待っている間に前面アプリが切り替わっても、対象アプリは変わりません。 | [待機](elements.md#待機timeout) |
| `xcui` 経路は遅い | XCUI はタッチの前後に対象アプリのアイドル待ちをするため遅くなります。 | [タッチ合成の経路](design.md#タッチ合成の経路) |

### 起動とセッション

| 症状・制約 | どうなるか（1 文） | 読む節 |
| --- | --- | --- |
| 入っていないアプリの `/launch` | 入っていないアプリの起動をランナーに送ると、XCTest がすぐには失敗せず長く busy になります。 | [アプリの指定と起動](cli.md#アプリの指定と起動) |
| シミュレータの自動用意はしない | セッションごとにシミュレータを複製・作成しないため、並列に動かす台数は利用者が用意します。 | [並列に使うシミュレータの用意](sessions.md#並列に使うシミュレータの用意) |
| シミュレータのランナーには Mac の外から届かない | シミュレータのランナーは `127.0.0.1` だけで待ち受けるため、ほかのマシンから直接は接続できません。 | [シミュレータへの接続](sessions.md#シミュレータへの接続) |
| セッションのポートの予約 | 予約は `relay start` どうしでしか効かず、待ち受けるまでにほかのプロセスが同じポートを使うと起動に失敗します。 | [ポートの自動選択](sessions.md#ポートの自動選択) |
| セッションと強制終了 | `relay start` を強制終了すると、ロックは外れますが xcodebuild とランナーが残ることがあります。 | [強制終了したとき](sessions.md#強制終了したとき) |
| 外部コマンドが応答しないとき | 外部コマンドは時間を区切って呼ぶので、応答がなければ relay はエラーを返します。 | [外部コマンドが応答しないとき](sessions.md#外部コマンドが応答しないとき) |

## 横断的な制約の説明

### 非公開 API への依存

タッチ合成の `private` 経路、前面アプリの取得、表示の向きの取得などは XCTest の非公開 API を使うので、Xcode / iOS の更新で使えなくなることがあります。
消えた場合の多くは代わりの手段に切り替わりますが、シグネチャだけ変わった場合は検出できません。
項目ごとの挙動は「[非公開 API の一覧](private-api.md)」を参照してください。

### 映像ストリームはまだない

画面はスクリーンショットのポーリングで取得します。シミュレータの縦向きで png は約 90 ms、jpeg は約 110 ms です。
横向きは正規化のぶん遅くなります。縮小（`maxSize` / `scale`）しても、XCUI の撮影自体（約 60 ms）は変わりません。

### 通信は平文

認証はトークンだけで、TLS はありません。脅威モデルは「[認証](http-api.md#認証)」を参照してください。
強制終了で残る状態ファイルは「[強制終了したとき](sessions.md#強制終了したとき)」、以前の版のファイルの扱いは「[カレントディレクトリのファイル](sessions.md#カレントディレクトリのファイル)」を参照してください。
